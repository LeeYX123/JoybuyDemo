阅读说明

以最新确认需求为准，本文按当前独立模块说明页面、每项功能、数据/表单字段、流程、校验及验收。字段表包含页面字段及该功能必需的关联数据，并不表示每个字段都在当前页面可编辑。原型与正式服务差异见共用字段与接口约定。接口名和数据表均为建议设计，尚未实现。

原型文件：海外电商平台管理后台.html；源码位置：work/admin/build.cjs。不修改原型，仅整理文档。

后台采用深色导航与蓝色操作风格；登录页在未登录时显示。账号密码和模块权限以后台登录身份为准，不继续使用任意切换演示角色。

全局交互约定

  • 页面列表的查询、重置、分页、空状态、错误状态要明确；修改筛选重置到第一页。商品相关页码居中，不显示件数说明。
  • 确认发货、上架、下架、解封、完成全部节点、资金入账等使用二次确认或明确的确认提交。加载时禁用重复提交，服务端仍要幂等。
  • 不增加多余宣传小字、店铺经营正常横幅、处罚/修改说明必填框。保留必要的字段标签、错误提示、业务状态和真实资金信息。
  • 图片保存失败不能留下仅修改了价格或记录的半成功状态。正式上传到文件服务，返回对象ID和URL。
  • 金额用CNY两位小数示例；订单成交金额和发货成本必须使用不同标签。
  • 数据归属、资金事务、会话授权和图片访问权都由服务端验证。

A01 登录与当前账号

验证管理员身份并按逐模块权限进入后台。

功能清单与交互

功能入口/触发处理与结果校验和边界
登录输入账号和密码启用账号且凭证正确才进入第一个有权限模块错误/停用提示统一，无可访问模块拒绝登录
会话恢复刷新后台匹配账号ID、凭证版本、启用状态原型sessionStorage，正式后端会话
当前账号顶部账号入口显示账号、姓名、角色不允许任意切换演示角色绕过账号权限
退出登录退出入口清会话并回到登录页不能继续通过旧页面触发操作

业务规则

  • 默认演示admin/Admin@123456仅用于本地原型，正式环境必须禁用默认凭证并提供初始化流程。
  • OP001超级管理员保持启用和全部模块权限，避免自锁。
  • 正式每个接口独立鉴权，前端隐藏菜单不构成安全边界。

流程

  1. 输入凭证
  2. 服务端验证
  3. 检查账号启用与权限
  4. 建立会话
  5. 进入授权模块
  6. 退出或凭证失效

A02 商家管理

审核开店、查看店铺资金和履约情况，管理封店与信誉。

功能清单与交互

功能入口/触发处理与结果校验和边界
列表与查询状态Tab、店铺名称/ID店铺ID、待发货总订单数/金额、钱包、保证金、状态、上次在线、入驻日期不显示联系人和经营站点
入驻审核待审核点击审核选择通过/驳回、是否保证金、保证金金额、未发货封店天数审核通过后保证金选择永远锁定，默认不勾选
商家详情编辑详情保存名称、钱包余额、信誉分、自动封店天数钱包非负两位小数，信誉0至100，天数整数至少1
扣除信誉分商家操作输入扣分数，展示最近扣分记录正数且不超过当前分数，不需要处罚说明
客服直接解封已封店操作二次确认后恢复接单，重置未处理订单履约计时无解封审核中，不显示钱包或保证金信息
预览商家端详情按钮按指定商家策略打开商家原型正式通过授权身份切换，不使用URL可伪造策略
导出商家导出按钮导出当前筛选商家与经营状态按模块查看权限控制

业务规则

  • 不再提供钱包/保证金处罚扣款功能。
  • 未缴初始保证金只是待缴状态并禁止上架，不自动封店，也不能存在其未经营却超时发货的订单。
  • 自动封店仅针对未处理订单超过该商家的整数天阈值，解封需联系客服。
  • 商家最后操作时间由商家端任何用户操作更新，不能由管理员查看商家详情替代更新。

流程

  1. 用户申请开店
  2. 审核保证金和封店天数
  3. 免缴直接开店或待缴
  4. 经营
  5. 超时自动封店
  6. 联系客服
  7. 手动解封

A03 商品池管理

维护平台商品的品类、图片、规格、价格和可售性。

功能清单与交互

功能入口/触发处理与结果校验和边界
搜索与列表商品ID/名称/品类缩略图、品类、成本、零售价、商家数、状态平台可售与某商家上下架分开
新增商品新增商品按钮名称、品类、图片、规格、成本、零售价、描述选择活动商品时保存activity标记
图片编辑上传/主图/移除最多5张图片，实时缩略预览，第一张主图单图1MB，JPG/PNG/WebP，存储失败不部分保存
规格编辑新增规格/移除填写规格名和值，支持多行名称30字、值200字，不能半行或同名重复
商品详情详情按钮展示完整图片、规格、描述和价格再次编辑保留已保存内容
平台下架或恢复商品池操作修改商品池可售性商家已有上架关系的处理方式待确认，不混同指定店铺下架

业务规则

  • 商品品类包括活动商品，总计12类。
  • 商品名称最多80字，成本和零售价为正，零售价不得低于成本。
  • 规格目前只是名称/值文本，不代表已实现SKU组合、库存和多规格价格。
  • 修改商品价格不能覆盖已生成订单的成本和成交价快照。

A05 订单管理

维护订单数据与物流节点，在确认收货时进行一次回款。

功能清单与交互

功能入口/触发处理与结果校验和边界
列表查询和导出全部/待处理/已发货/已完成按订单号、商家、商品和下单日期查询没有催发货按钮和超时状态Tab
订单详情详情按钮订单号、商家、商品、数量、下单时间、支付方式、金额、成本、状态和8节点后台保留节点以便编辑，商家只在未完成时显示
修改下单时间详情按钮编辑datetime并记录原值与新值不得晚于已有首个有效节点时间
修改节点时间详情按钮逐个编辑8个节点的日期时间空值可保留，时间有序不早于下单；修改时间不自动重复回款
更新订单进度已发货订单选择新的节点及物流凭证不能回退或重复同一节点，最后节点触发回款
一键完成全部节点当前订单详情二次确认推进当前订单到用户确认收货只影响当前一笔，不是全平台全部订单
回款事务节点到用户确认收货状态已完成、钱包加订单额、生成订单回款和通知以订单ID幂等，重复提交无额外资金变动

业务规则

  • 订单状态与节点是两个字段，状态仅3种。
  • 一键完成会保留已设置时间，按时序补齐空时间；有未来时间需先调整。
  • 已完成订单的节点时间仍可由授权管理员修改，但不得取消已经入账的事实。
  • 确认收货后不再存在订单完成、回款中、回款完成三个节点。

流程

  1. 查询单个订单
  2. 查看状态与节点
  3. 可改时间或更新节点
  4. 二次确认一键完成（可选）
  5. 用户确认收货
  6. 已完成并一次回款

跨端联动与端到端流程

入驻、保证金与开店

  1. 用户提交入驻申请
  2. 后台审核：是否需保证金、金额、未处理封店天数
  3. 免缴：直接接单中；需缴：待缴保证金
  4. 客服在保证金管理充值
  5. 首次缴足：接单中并允许上架
  6. 审核后的保证金选择永久锁定

发货、确认收货与订单回款

  1. 订单待处理，保存成本/单价/支付方式快照
  2. 商家确认发货：校验钱包≥成本合计
  3. 原子扣成本、生成订单发货流水，状态已发货
  4. 后台/物流按8节点推进并记录时间
  5. 用户确认收货：状态已完成
  6. 钱包增加订单成交金额，生成一次订单回款
  7. 商家详情隐藏整个进度区，收益标签为盈利

提现审核和出款

  1. 商家填写银行卡或数字货币链上收款信息
  2. 金额不超过钱包可用余额
  3. 验证6位钱包密码，创建待审核并占用余额
  4. 后台审核：通过或打回（打回退回一次）
  5. 审核通过：记录凭证，开始转账
  6. 到账：结束；失败：退回一次
  7. 商家统一资金明细显示全过程

推荐返佣核算与人工到账

  1. 商家复制推荐码分享
  2. 新人入驻绑定推荐关系
  3. 按每位新人当月发货成功金额统计
  4. 每月1日冻结上月返佣快照，状态待发放
  5. 客服7个工作日内确认返佣
  6. 原子加推荐商家钱包，生成推荐返佣流水
  7. 商家活动和钱包均显示已到账；重复确认无效

商品好评推送和多轮回复

  1. 后台输入店铺ID搜索
  2. 按名称/商品ID搜索本店已上架商品
  3. 填写通知标题、评论，图片可选
  4. 推送后商家未读通知
  5. 商家查看商品、文字、图片、最后一行时间
  6. 商家回复，后台同一记录继续回复
  7. 平台新回复使商家重新未读

白名单余额购买

  1. 用户已注册商城账号
  2. 后台搜索账号并加入白名单
  3. 后台向白名单账号充值
  4. 商城校验启用状态和地区/白名单
  5. 服务端获取订单真实应付金额
  6. 余额足够时一次扣款并写消费记录
  7. 移出白名单取消专属权限，余额和历史保留

超时自动封店与客服解封

  1. 订单仍待处理且商家已具备经营资格
  2. 按商家未处理整数天数检查超时
  3. 自动封店并生成原因、日志、通知
  4. 商家联系客服
  5. 客服在商家管理二次确认解封
  6. 恢复接单，重置未处理订单履约起算时间
  7. 不扣钱包或保证金，不存在解封审核中

管理员账号与权限

  1. 超级管理员新增登录账号、密码、姓名
  2. 选择角色模板与每模块查看/操作权限
  3. 保存摘要、账号状态和权限
  4. 新账号登录并检查启用和可访问模块
  5. 按权限显示菜单，接口逐项鉴权
  6. 密码/权限变更使旧会话按策略失效
  7. 退出登录回到登录页
