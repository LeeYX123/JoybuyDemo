# Joyplay 商家端移动设计交接

## 如何查看

解压整个 ZIP，保持所有文件在同一个目录，然后用 Chrome 或 Safari 打开 Joyplay-folio.html。电脑上会居中显示手机宽度的页面。无需安装 npm 依赖或启动服务器。

## 文件用途

- Joyplay-folio.html：最终手机设计的预览入口。
- 寰球优选-商家端三案预览.html：共享页面、演示数据和原有交互。文件名沿用历史名称，应从 Joyplay-folio.html 进入最终设计。
- merchant-mobile.js：移动端界面、会话、导航和弹层。
- joyplay-mobile.css、joyplay-concepts.css：移动端基础样式与最终视觉样式。
- merchant-mobile.css：共享 HTML 引用的基础文件，请一并保留。

## 开发接入范围

- 以该原型作为移动网页和 WebView 的视觉与交互参考。示例业务数据保存在浏览器本地。接入时复用现有生产 API、登录及权限逻辑。
- 顶部「切换去商城」目前为交互预览。开发时接入实际商城入口。
- 顶部语言选择只演示选中状态和顶部文案。正式接入时复用商城的语言偏好和翻译资源，商城与商家端使用同一设置。
- WebView 真机、系统返回键、键盘及文件选择器仍需在原生宿主中验证。

## 验收重点

1. 订单详情默认显示当前履约进度，通过「查看全部进度」展开。已完成订单隐藏进度区。
2. 无关联订单的会话省略订单号，回复不受影响，发送按钮位于右下角。
3. 首页保留店铺头像、资料编辑和分组业务入口。图表直接展示每天数值。
4. 核对 375、390、430 px 的实际页面，检查顶部工具、表单和底部操作。
