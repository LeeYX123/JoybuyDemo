# 页面清单与视觉验收

## 1. 基线原则

1. 实施开始时，对 Joybuy 当前网站建立固定基线；
2. 保存页面截图、DOM 摘要、接口样例、资产 URL、内容哈希、抓取时间和浏览器版本；
3. 开发过程中 Joybuy 的后续改版不自动改变验收基线；
4. 变更进入清单，经确认后再同步；
5. 购物端依据公开页面 1:1 复刻；非公开的商家端和平台端不宣称 1:1。

## 2. 购物端页面域

### 2.1 发现与浏览

- 首页、全局页头、导航、页脚；
- 一级/二级/三级类目；
- 搜索结果、自动建议、空结果；
- 品牌馆、店铺/品牌展示页；
- 活动、Marketing、Campaign、Explore、欢迎优惠；
- 会员、积分、优惠券和礼品卡展示页；
- 博客、帮助中心、条款和政策内容页。

### 2.2 商品

- 商品卡片的所有公开形态；
- 商品详情、SKU 选择、图库、视频、价格和单位价；
- 配送提示、库存提示、商家信息和服务标签；
- 商品描述、规格、推荐位；
- 评分分布、评价列表、评价媒体查看器和分页。

### 2.3 账户与交易

- 邮箱/手机号注册登录、验证码、找回密码；
- 收藏、最近浏览、地址、通知和基础资料；
- 购物车：空态、普通态、不可售/失效商品；
- 结算：地址、邮编、配送/自提、运费和订单确认；
- 支付不可用提示；
- 待支付和已取消订单列表、详情。

### 2.4 非首期真实功能

以下页面可复刻外观或显示占位说明，但不得伪装为已接入能力：

- 真实支付和支付成功；
- 礼品卡购买/抵扣；
- 物流、售后、退款；
- App 独占流程；
- 第三方在线客服。

## 3. 页面状态矩阵

每个核心页面至少验证：

- 未登录 / 已登录；
- 加载中 / 成功 / 空数据 / 失败；
- 默认、hover、focus、disabled、selected；
- 窄屏、宽屏和文字换行；
- 长标题、缺图、视频、多个 SKU、无评价和大量评价；
- 英文和简体中文的布局伸缩；
- 单一原价展示（美元 `$` 符号、无划线价）、普通促销标签与"今日送达"类标签被过滤的展示；
- 购物车为空、有商品、商品失效；
- 订单待支付、超时取消。

## 4. 视觉对比环境

- 基准视口：`1440x900`、`1280x800`、`390x844`、`375x812`；
- 固定 Chromium 版本、设备像素比、字体包、时区和 locale；
- 禁用动画或将动画停在固定时间点；
- 使用固定测试数据，冻结时间、轮播和随机推荐；
- 对来源站与复刻站生成同尺寸截图；
- 整页差异目标 `<= 2%`；
- 页头、导航、商品卡、详情主区、购物车、结算关键区 `<= 1%`；
- 自动差异报告必须附带热力图和人工结论。

## 5. 资产规则

- 禁止热链 Joybuy 或任何第三方 CDN；
- 下载并本地托管允许使用的图标、字体、图片和视频；
- 每个来源资产记录原 URL、抓取时间、SHA-256、MIME、尺寸、用途和本地相对路径；
- SVG、图标字体、普通图片和视频分别管理；
- 构建依赖打包到本地产物，运行时不从公共 CDN 拉取；
- 来源文件和前端优化衍生文件均保留。
